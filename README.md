# Claude Code plugins

Plugins taken from a working Claude Code setup. Install the ones you want; each works on its own.

```text
/plugin marketplace add dev-jayp/claude-plugins
/plugin install session-manager@dev-jayp-plugins
/plugin install session-hygiene@dev-jayp-plugins
```

| Plugin | What it does |
|---|---|
| [session-manager](plugins/session-manager) | List, archive, restore, and safely delete your Claude Code sessions across every project. |
| [session-hygiene](plugins/session-hygiene) | Save the model's working notes before Claude Code auto-compacts a conversation, and hand them back afterwards. |

More plugins will be added here as they are made general enough to share.
